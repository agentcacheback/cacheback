Recording details and text description

Seven Qwen3-8B workers pass information to a coordinator. The supplied bug report identifies a missing save_m2m() call in Django’s user creation form. Both runs add that call after saving the user. The CacheBack run finishes while the text workers are still generating reports.

The interface is reconstructed from separate recorded runs, aligned at their start. The final response and patch come from the recorded outputs. Both patches subsequently pass one new test and 87 regression tests; grading is outside the clocks. This is an individual demonstration, not an aggregate benchmark. Recorded results

TL;DR

Agents can share internal model state instead of writing reports. Sending all of it, however, overwhelms the receiver.

The receiver asks for what it needs. CacheBack uses attention to that request to select which state gets sent. Simple, robust, and training-free.

Use CacheBack

Install rclc, bind your agents, and pass the receiver’s request.

Code and documentation

Local Qwen 3 weights, using Hugging Face or vLLM.
Hosted chat APIs do not expose the required state.

Python
import rclc

sender = rclc.bind(
    model, tokenizer,
    messages=sender_history, backend="hf",
)
receiver = rclc.bind(
    model, tokenizer,
    messages=receiver_history, backend="hf",
)
await rclc.transfer(
    sender, receiver,
    "Who owns the Cedar booking?",
)
inputs = receiver.pop()

Model, tokenizer, and histories loaded; run in an async function or notebook. Runnable quickstart
